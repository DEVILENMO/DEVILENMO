## 兴趣项目

这些项目大多不是工作需要，只是某个时候突然想做，于是就做了。它们不一定都很“实用”，但每一个都记录了一点当时感兴趣的东西。

### [DeadEye Auto-Aiming System](https://github.com/DEVILENMO/DeadEye-Auto-Aiming-System)

最早只是想试着做一个辅助瞄准，后来慢慢写成了一个基于 YOLO 的目标追踪系统。现在回头看，它更像是我早期折腾视觉算法时留下的一份完整记录。

### [VAE-CycleGAN Unsupervised Defect Detection](https://github.com/DEVILENMO/Unsupervised-Defect-Detection-Project-Based-on-VAE-GAN-Architecture)

这是硕士期间参加比赛时做的一个算法项目，把 VAE 和 CycleGAN 结合起来，用图像重建的方式做无监督缺陷检测。只需要提供个位数的完整产品图片作为参考，就可以开始检测缺陷，算是接近 zero-shot 的方案。

### [ARC Search Engine](https://github.com/DEVILENMO/ARC-Search-Engine)

港科大「搜索引擎与技术」课程项目。做了一个支持任意 UTF-8 语言的 AI 搜索引擎，从爬虫、索引、排序一路做到搜索结果，过程还挺有意思，就把它记录在这里。

### [ARC Minecraft · 弧光](https://github.com/ARC-Minecraft)

> 面向整个 Minecraft **基岩版**的完整开发生态 —— 工具、服务端插件、内容创作与社区互通。  
> 组织主页：[github.com/ARC-Minecraft](https://github.com/ARC-Minecraft)

弧光是我和朋友们一起折腾出来的 Minecraft 基岩版开发生态，项目从服务端插件出发，也逐渐扩展到了世界维护、Addon 工具、AI 能力和社区互通。这里既有实际运营服务器需要的基础设施，也有一些单纯觉得有意思就做出来的东西：

- [**ARC Core**](https://github.com/ARC-Minecraft/EndstoneMC-ARC-Core-Plugin) 是整个生态的底座，经济、头衔等基础功能都放在这里。
- [**Button Shop**](https://github.com/ARC-Minecraft/EndstoneMC-ARC-Button-Shop-Plugin)、[**Prison**](https://github.com/ARC-Minecraft/EndstoneMC-ARC-Prison-Plugin) 和 [**Ups & Downs**](https://github.com/ARC-Minecraft/EndstoneMC-ARC-Ups-And-Downs) 负责商店、监狱服和股票交易这些玩法。
- [**QQ Sync**](https://github.com/ARC-Minecraft/EndstoneMC-ARC-QQ-Sync-Plugin) 配合 [**AstrBot Hub**](https://github.com/ARC-Minecraft/AstrBot-ARC-EndStoneMC-Hub)，把 Minecraft、QQ 和不同服务器连接起来。
- [**AI Builder**](https://github.com/ARC-Minecraft/EndstoneMC-ARC-AI-Builder) 和 [**AI Helper**](https://github.com/ARC-Minecraft/EndstoneMC-ARC-AI-Helper) 是我拿 AI 往游戏服务器里硬塞的尝试。
- [**Addon Auto-Localizer**](https://github.com/ARC-Minecraft/ARC-MCBE-Addon-Auto-Localizer) 则是一个给基岩版 Addon 自动汉化的小工具。

更多插件与工具见组织仓库列表。
